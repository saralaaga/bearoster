## 描述（上限 4000）

```
蓝熊名册是一款完全在本机运行的 macOS 通讯录工具，重点是生日。

它读的是系统「通讯录」里的真实数据，改的也是同一份数据——不导入、不复制、不上传，改完在「通讯录」App 里立刻就能看到。

生日
· 支持公历、农历、希伯来历、伊斯兰历四种历法
· 日历视图按月展示，一眼看清这个月谁过生日
· 生日列表按「最近生日」排序，也能筛出近期生日
· 语音输入：念一句「三月十五」，自动转成正确日期

整理通讯录
· 标签系统，支持多层子标签，比如「朋友 / 大学同学」
· 按 Apple 分组、标签、资料缺失情况筛选；多个条件可以叠加，支持「满足全部」或「满足任一」
· 一次编辑多位联系人，保存前先预览每一处改动
· 默认只填空缺项，不会覆盖你已经写好的内容——除非你明确要求

为什么放心
· 通讯录内容不会离开你的 Mac——不上传、不同步、不连接任何第三方服务器
· 不收集数据。没有埋点、没有分析、没有第三方 SDK
· 不需要注册或登录，没有账号系统
· 只有两处权限：通讯录（读取和更新），以及麦克风 + 语音识别（只在你主动使用语音输入时才启用）

系统要求
macOS 14 或更高版本。
```
