# 年龄分级问卷答案（Age Rating）

App Store Connect → 年龄分级 → 按下面的答案逐项填写。预期结果：**4+**。

## 逐项答案

| 问卷项 | 答案 |
|---|---|
| 卡通或幻想暴力 | 无 |
| 写实暴力 | 无 |
| 长期暴力画面 | 无 |
| 恐怖或惊悚主题 | 无 |
| 性内容或裸露 | 无 |
| 低俗幽默 | 无 |
| 亵渎或粗俗幽默 | 无 |
| 酒精、烟草或药物使用 | 无 |
| 模拟赌博 | 无 |
| 性内容或裸露（含暗示） | 无 |
| 医疗/治疗信息 | 无 |
| 用户生成内容 | 无 |
| 用户间通讯 | 无 |
| 广告 | 无 |
| 位置信息 | 无 |
| 不受限制的网页访问 | 无 |

**预期结果：4+**

## 依据

- App 不联网，无法显示外部内容。
- 没有社交功能、没有用户间通讯、没有 UGC 上传。
- 显示的内容全部来自用户自己的通讯录，属于本机已有数据。
- 如果 Apple 问到「是否会显示来自互联网的内容」，答案是否。

## 备注

通讯录中的生日会显示年龄，但不涉及暴力、成人内容等任何受分级约束的类别。若 Apple 后续增加新的问卷项，按「无 / 否」作答即可，除非引入联网或社交功能。
