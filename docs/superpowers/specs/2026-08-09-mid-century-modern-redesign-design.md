# Roster Mid-Century Modern 重设计 · 设计文档

日期：2026-08-09
状态：方向由用户指定（1950–60 年代中世纪现代设计美学），取代奶油橘方案
交付物：本设计文档 + `app/redesign-mcm.html` 静态 demo（不改 Swift 代码）
对比版本：奶油橘方案保留于 `app/redesign-warm.html` 与
`2026-08-09-warm-redesign-design.md`，评审后可删除落选版本

## 1. 设计方向

Mid-Century Modern：简洁、功能性与有机美学的平衡；战后乐观主义——温暖、友好、开放。
界面保持 Roster 的工具属性与信息架构不变（侧边栏四项 + 日期选择器组件），
仅替换视觉语言。装饰元素（星爆、原子图形、几何条纹）克制使用，服务于信息层级。

## 3. 字体与排版

- 字族：`"Avenir Next", Futura, "Century Gothic", -apple-system, "PingFang SC"`（标题与正文同族，字重区分层级）。
- 页面标题：大号粗体（22px/700），日历月份标题 19px/700。
- 小标签（侧边栏分组、表单标签、按钮）：全大写 + `letter-spacing:.12–.16em` + 11–12px/700；
  中文环境退化为加字距的常规大小写。
- 正文 13–14px，行距 1.5 左右；数字信息用 500–600 字重保证清晰。

## 4. 视觉元素

- **星爆（starburst）**：✳ 形符号，仅用于「今天」标记（日历格子、倒计时、当日详情卡）
  和侧边栏「即将到来」卡片，颜色用橙红或芥末黄。
- **原子时代图形**：三椭圆交叉的原子符号（inline SVG），仅一处——主日历工具栏右侧，
  低透明度（15–20%），作为时代氛围点缀。
- **几何条纹**：橙红/芥末/橄榄三色细条纹（各 3–4px 高），用于侧边栏顶部标题区下沿
  和设置页卡片顶部，呼应木质镶嵌工艺。
- **有机几何**：头像保持圆形；按钮、徽章为微圆角矩形（6–8px）或全胶囊；
  卡片圆角 10px（比奶油橘方案更克制，更"现代主义"）。
- **细线感**：图标与分隔用 1px 木质调线条，呼应细腿家具的轻盈。

## 5. 布局

- 开放式、通透：内容区留白加大（页边距 22–26px），卡片间距 16–20px。
- 非对称但平衡：日历页维持「月格 + 右侧详情栏」的非对称结构；
  设置页卡片左对齐、限宽 640px，右侧留呼吸空间。
- 水平延展：工具栏元素一字排开；生日列表行充分利用横向空间，倒计时胶囊右对齐。
- 模块化网格：月历 7 列等宽网格；组件页卡片 2 列流式排布。

## 6. 页面与组件

四个应用页面 + 日期选择器组件页的信息架构与奶油橘方案完全一致
（见 `2026-08-09-warm-redesign-design.md` §3），此处只列 MCM 视觉差异：

- **侧边栏**：选中项为胶囊形橙红 12% 底 + 橙红文字；底部「即将到来」卡片
  改为柚木→胡桃木渐变，配星爆符号与芥末黄倒计时胶囊。
- **日历页**：今日 = 橙红描边圆 + 星爆角标；选中 = 芥末黄 18% 底；
  格子内的生日用**姓名标签**呈现（10px 白字、四历语义色实底、4px 圆角、超长省略），
  每格最多 2 个，超出显示「+N」；
  非本月格子置灰——去卡片底与边框、文字弱色、标签去饱和（grayscale + 降不透明度）。
- **列表页**：「今天」行 = 橙红 8% 底 + 星爆 + 橙红实底胶囊；其余倒计时 = 芥末黄 20% 底。
- **联系人编辑**：历法分段控件为微圆角矩形（8px）；选中态橙红实底白字；
  「清除生日」用珊瑚粉文字按钮。
- **设置页**：权限状态点橄榄绿；卡片顶部三色条纹装饰。
- **日期选择器**：结构不变（公历迷你月历 / 月年跳转 / 三列滚轮），
  选中态统一橙红实底，今天为橙红描边。

### 6.1 通讯录分组（新 feature）

- 侧边栏「管理」区下方新增「分组」区块，列出 Apple 通讯录分组（`CNGroup`），
  每个分组带一个语义色小圆点（橙红=家人 / 灰蓝=同事 / 橄榄绿=球友 / 芥末黄=老友，
  颜色按序循环分配）和成员计数。
- 「全部联系人」为默认项；点击分组即筛选生日列表与联系人编辑页，
  并跳到联系人页。分组为空时不显示。
- 分组只读：Roster 不创建/修改分组，仅读取并用于筛选（与「通讯录是唯一数据源」一致）。

### 6.2 联系人标签（新 feature）

- 标签是用户自定义的轻量标记（如「至亲」「每年聚餐」），与 Apple 分组正交。
- 样式：微圆角矩形（5px）小胶囊，10px/700 文字 + 大写化字距，
  四种柔和配色循环——芥末黄底、橄榄绿底、灰蓝底、珊瑚粉底（14–22% 不透明度底 + 实色文字），
  与 MCM 色板同源。
- 出现位置：生日列表行、联系人列表项（姓名下方的 meta 行，最多 2 个，超出 +N）、
  联系人编辑表单。
- 编辑：表单内「标签」卡——已有标签带 × 可移除；末尾「＋ 添加标签」虚线框按钮。
- 存储（落地时）：通讯录无原生标签字段，标签写入 `CNContact.note` 的受控片段
  （如 `[tags: 至亲, 球友]`），解析容错、不覆盖用户其他备注——保持通讯录为唯一数据源。

### 6.3 生日条目跳转（新交互）

日历格子的姓名标签、当日详情卡、生日列表行、侧边栏「即将到来」卡片，
点击后统一跳转到联系人页并**聚焦该联系人**：左侧列表高亮 + 1.1s 底色渐隐的聚焦动画，
右侧表单渲染该联系人的生日类型、日期、标签与所属分组。
公历以外的历法才显示「闰月」开关；换算说明随历法切换文案
（公历 = 「今年生日：…」，其他历法 = 「对应公历：…」）。

## 7. 动效规范

原则：平滑、自然、功能优先；动效帮助理解层级与状态变化，绝不喧宾夺主。
统一缓动 `cubic-bezier(.25,.6,.3,1)`（自然减速），所有动效遵守
`prefers-reduced-motion`（开启后全部退化为无动画）。

| 场景 | 时长 | 效果 |
| --- | --- | --- |
| 页面切换 | 220ms | 淡入 + 上移 8px，ease-out |
| 列表/日历进入 | 260ms | 行逐项淡入上移，每项延迟 25–30ms（ stagger ） |
| 悬停（行/按钮/格子） | 120ms | 背景色淡入，无位移 |
| 按钮按压 | 100ms | scale(.97)，松手回弹 |
| 侧边栏选中 | 180ms | 底色淡入 |
| 月份切换 | 220ms | 整月网格水平滑动（方向随前进/后退）+ 月份标题数字滚动 |
| 弹层（日期选择器等） | 160ms | 淡入 + scale(.96→1)，以触发点为锚 |
| Toast 提示 | 200ms | 底部上滑淡入；停留 2.4s 后淡出 |
| 「今天」星爆 | 4s 循环 | scale 1→1.08→1 轻柔脉动（仅装饰，可关） |

落地 SwiftUI 时对应 `.animation(.easeOut(duration:), value:)` 与
`withAnimation`，环境变量 `accessibilityReduceMotion` 处统一降级。

## 8. Demo 规格

- 单文件 `app/redesign-mcm.html`，纯 HTML/CSS/原生 JS，无外部依赖，双击可开。
- 顶部分段控件切换五个视图（四应用页 + 日期选择器组件页）；亮/暗切换，
  默认跟随系统。
- 动效（§7）在 demo 中真实实现：页面切换、列表 stagger、悬停、按压、
  星爆脉动均可见。
- 分组筛选在 demo 中为真实交互：点击侧边栏分组即筛选列表/联系人页（§6.1）。
- 生日条目点击跳转联系人页并聚焦（§6.3）在 demo 中真实可用。

### 8.1 移动端适配（≤820px）

demo 为响应式，窄屏（手机/小窗）下的布局策略，供未来 iOS 版参考：

- **导航**：侧边栏收起为底部 Tab 栏（日历 / 列表 / 联系人 / 设置），
  选中态橙红；「即将到来」卡片与品牌区随侧边栏隐藏。
- **分组**：变为页面顶部的横向滑动胶囊筛选条（列表页、联系人页均有），
  与侧边栏分组状态双向同步；点击只筛选、不强制跳页。
- **日历页**：月格与当日详情由左右分栏改为上下堆叠；格子收紧（58px 最小高、
  姓名标签 9px），搜索框独占一行，原子图形隐藏。
- **联系人页**：联系人列表变横向滑动头像条（隐藏副标题），表单在其下整宽排列。
- **设置页**：设置项的标签与控件由左右改为上下排列。
- **选择器组件**：单列堆叠，宽度撑满（上限 304px）。
- 窗口装饰（交通灯、圆角、投影）在移动端移除，内容全屏。
- 示例数据与奶油橘 demo 相同（9 位联系人、四历法、含今天/明天），便于对照评审。
- 文案：简体中文。

## 9. 后续落地 SwiftUI 的映射（仅说明）

- `RosterTheme` 替换为 MCM 色板（light/dark 双套），`color(for:)` 按 §2.3 更新。
- 标题字体改用 Avenir Next / 自定义字族 + `.bold()`；小标签加 `tracking` 与大写处理。
- `cardStyle()` 圆角 10px、木质调描边与软阴影。
- 星爆可用 SF Symbols 之外的自定义 ✳ 文本或简单 Path 绘制；原子图形为装饰性 SVG/Path，仅一处。
- 其余结构（AvatarView / KindBadge / CountdownChip / 选择器组件）不变，仅换色值与圆角。

## 10. 验收标准

- demo 打开即呈现五个视图，亮/暗正常，无外部资源请求。
- 星爆、原子图形、三色条纹各就其位且不过量；四历语义色与文档一致。
- §7 动效表中的效果在 demo 中可观察（页面切换、stagger、悬停、按压、星爆脉动）。
- 侧边栏分组可点击筛选；标签样式在列表、联系人、编辑三处一致。
- 与奶油橘版本并存，供用户对照后选定最终方向。
