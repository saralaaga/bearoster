# Birthday 温暖风格重设计 · 设计文档

日期：2026-08-09
状态：已与用户确认方向（奶油橘调 / 四页全覆盖 / 单文件自包含 HTML demo）
交付物：本设计文档 + `app/redesign-warm.html` 静态 demo（不改 Swift 代码）

## 1. 背景与目标

Birthday 是一个 local-first 的 macOS 通讯录生日管理工具（SwiftUI，UI 集中在
`Sources/BirthdayApp/RootView.swift`）。当前主题为粉红 + 橙，整体偏冷、偏工具感。

目标：以「温暖」为核心情绪重新设计视觉风格，覆盖全部四个主要界面（日历仪表盘、
生日列表、联系人编辑、权限与设置），先以 HTML 静态 demo 验证方向，不改实现代码。

非目标：

- 不改任何功能、交互流程、信息架构（侧边栏四项、月视图/近期切换等均保留）
- 不引入插画、纸屑动画等庆祝化装饰
- 不产出 SwiftUI 代码（本文档仅给出后续落地的映射说明）

## 2. 设计语言：奶油橘 · Cream & Coral

核心感受：阳光晒在贺卡纸上。暖白底、珊瑚橘强调、圆润形状、暖调阴影。
保持 macOS 原生工具的克制与可信度，不卖萌、不营销化。

### 2.3 历法语义色

四历色彩统一收入暖色盘，亮/暗各一套：

| 历法 | 浅色 | 深色 |
| --- | --- | --- |
| 公历 Gregorian | 杏橙 `#E8883C` | `#FFAB6B` |
| 农历 Chinese Lunar | 朱红 `#D64541` | `#FF6F6B` |
| 希伯来历 Hebrew | 梅紫 `#A06CD5` | `#BE9AEE` |
| 伊斯兰历 Islamic | 橄榄绿 `#7A9E4E` | `#A3C26E` |

徽章用法：语义色文字 + 语义色 13% 不透明度底，胶囊形（沿用现有 `KindBadge` 模式）。

### 2.4 字体与形状

- 标题：`ui-rounded, "SF Pro Rounded", system-ui`，semibold/bold；对应 SwiftUI
  `.fontDesign(.rounded)`。正文与数字用系统字体（`-apple-system`）。
- 圆角：卡片 16px（现有 12px 加大）；按钮、徽章、倒计时全部胶囊化；输入框 10px。
- 头像：圆形，暖色柔和渐变（语义色 85% → 100%），白色首字母（沿用现有 `AvatarView` 模式）。
- 控件尺寸遵循 macOS 规范：小按钮高 24px、常规 28px，点击热区不小于 24×24。

### 2.5 情绪细节（克制）

- 内容区背景叠一层极淡的暖色径向光晕（杏黄 6% → 透明，位于右上角）。
- 「今天生日」条目：珊瑚底白字倒计时胶囊 + 🎂，卡片描边用强调色 30%。
- 侧边栏底部「下一个生日」卡片：杏黄 → 珊瑚 135° 渐变底，白字，作为全窗情绪锚点。
- 除此之外无插画、无动画装饰；过渡动效统一 150ms ease。

## 3. 页面设计

四个页面共享：左侧边栏（约 220px）+ 顶部工具栏 + 内容区。窗口最小 980×640。

### 3.1 日历仪表盘（默认页）

- 工具栏：月份标题（rounded bold）+ 上月/下月 chevron + 「今天」胶囊按钮；
  右侧「月视图 / 近期」分段控件（胶囊式）+ 刷新按钮 + 搜索框。
- 月视图：7 列格子，格子为圆角 12px 的暖白卡片；有生日的日期在数字下方放
  语义色圆点 + 迷你头像（最多 3 个，超出 +N）。今天：强调色圆形底白字。
  选中日：强调色 12% 底 + 强调色描边。
- 右侧当日详情栏（300px）：日期标题 + 当日生日卡片列表（头像、姓名、
  历法徽章、年龄/倒计时）；无生日时显示暖调空态（「这一天没有人过生日」）。
- 近期模式：按时间顺序的列表，复用 3.2 的行样式。

### 3.2 生日列表

- 按月份分组的时间线，组标题为「M月」+ 组内计数。
- 行：左 avatar + 姓名 + 历法徽章 + 生日日期（含历法原文，如「腊月初八」），
  右侧倒计时胶囊（今天 = 珊瑚实底白字 + 🎂；其余 = 珊瑚 12% 底珊瑚字）。
- 行悬停：暖调填充；点击行进入联系人编辑（demo 中无交互，仅视觉）。

### 3.3 联系人编辑

- 左：联系人列表（可搜索，头像 + 姓名 + 是否已填生日的小圆点指示）。
- 右：选中联系人的分组表单卡片——
  - 生日类型：胶囊分段控件（公历 / 农历 / 希伯来历 / 伊斯兰历）
  - 日期输入：年月日三栏（农历额外有「闰月」开关）
  - 「清除生日」为暖红色文字按钮；保存为主强调色胶囊按钮。

### 3.4 权限与设置

- 权限状态卡：橄榄绿（已授权）/ 珊瑚（未授权）状态点 + 说明文字 + 操作按钮。
- 设置分组卡：界面语言（简中/繁中/English 分段控件）、外观（跟随系统/浅色/深色）。
- 关于卡：版本号、简短说明，弱文字。

### 3.5 日期选择器组件（新增）

日历类 UI 元素的统一设计，demo 中有独立组件页集中展示。

- **公历日期选择器**：迷你月历弹层（272px 宽）。头部 ‹ 年月 › 导航；日期为圆形格子，
  今天 = 珊瑚描边，选中 = 珊瑚实底白字；前后月日期弱化显示；底部「清除 / 回到今天」。
  用于联系人编辑中的公历生日输入（替换简单下拉）。
- **月份 / 年份跳转选择器**：主日历工具栏点击月份标题时弹出，两级钻取——
  年份网格（十年一页，4 列）→ 月份网格（3 列）。选中项用强调色 12% 底 + 强调色文字。
- **农历日期选择器**：三列滚轮（年 / 月 / 日），月份含「闰×月」条目并随年份动态出现，
  下方「闰月」开关；底部实时显示对应公历日期。落地 SwiftUI 时为 `.wheel` 样式 Picker。
- **希伯来历 / 伊斯兰历选择器**：与农历选择器同构的三列滚轮，
  月份名随界面语言本地化（如 Elul、Rabiʻ I）。

## 4. Demo 规格

- 单文件 `app/redesign-warm.html`，纯 HTML/CSS/少量原生 JS，无任何外部依赖，
  双击即可在浏览器打开。
- 顶部分段控件切换五个视图：四个应用页面 + 一个 demo 专属的「日期选择器」组件页（§3.5）；
  右上角亮/暗模式切换（写入 `data-theme`，默认跟随系统 `prefers-color-scheme`）。
- 窗口外观模拟 macOS：红黄绿交通灯、圆角窗口、暖色窗口阴影。
- 示例数据：8–10 个虚构联系人，覆盖四种历法，含 1 个「今天生日」、
  1 个「明天」，保证关键状态都可见。
- 文案语言：简体中文（与 demo 预览场景一致）。
